# VeriBuy — AI Product Verification Platform (Master Prompt)

## Project Overview

Build a premium, Apple-inspired, single-page web application called **VeriBuy** that helps users verify the authenticity and trustworthiness of products before purchasing them online.

The core experience is simple:

- The user pastes a product URL from an e-commerce platform (Amazon, Flipkart, Meesho, Myntra, Ajio, eBay, Walmart, etc.).
- An AI Verification Engine performs a comprehensive background analysis.
- The website displays a professional report that helps users decide whether the product is safe to purchase.

**Important:** If the application is not connected to real APIs, clearly label the analysis as a **simulation/demo**. If real integrations are available, perform actual checks and only display completed analyses.

6. Compare prices across supported marketplaces where matching product data is available.
7. Estimate counterfeit or authenticity risk using available evidence.
